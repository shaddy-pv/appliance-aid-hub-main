## 🎬 Animation Examples

### Entrance Animation
```tsx
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.6 }}
>
  {/* Your content */}
</motion.div>
```

### Hover Effect
```tsx
<div className="hover:scale-105 hover:-translate-y-2 transition-all duration-500">
  {/* Your content */}
</div>
```

### Gradient Text
```tsx
<h1 className="bg-gradient-to-r from-indigo-600 via-purple-600 to-pink-600 bg-clip-text text-transparent">
  Your Heading
</h1>
```
