## 🎬 Animation Features

### Entrance Animations
```typescript
// Fade + Slide
initial={{ opacity: 0, y: 20 }}
animate={{ opacity: 1, y: 0 }}

// Staggered Children
variants={container}
initial="hidden"
whileInView="show"
```

### Hover Animations
```typescript
// Scale + Lift
hover:scale-105 hover:-translate-y-2

// Glow Effect
hover:shadow-[0_0_30px_rgba(79,70,229,0.5)]
```

### Background Animations
```typescript
// Pulsing Orbs
animate={{ 
  scale: [1, 1.2, 1],
  opacity: [0.3, 0.5, 0.3],
}}
transition={{ duration: 8, repeat: Infinity }}
```
